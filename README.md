# 🛍️ Forever - E-Commerce Frontend

A modern and responsive e-commerce frontend built using **React**, **Vite**, and **Tailwind CSS**. The application provides a clean shopping experience with product browsing, filtering, searching, cart management, and responsive UI.

> 🚧 **Note:** This repository currently contains only the frontend. The backend (authentication, APIs, database, payment integration, etc.) is under development.

---

## 🌐 Live Demo

🔗 **Website:** https://ecommerce-app-wl3e.vercel.app/

- 🏠 Responsive Landing Page

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/abhinavvv12/Ecommerce-App.git
```

### Navigate to Frontend

```bash
cd Ecommerce-App/frontend
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```
